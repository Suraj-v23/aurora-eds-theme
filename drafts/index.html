Features

Everything a launch page needs

Built on the official Adobe boilerplate, so upgrades and tooling keep working.

Rebrand in one file

Colors, radius, shadows and gradient are CSS variables at the top of styles.css.

No build step

Vanilla JavaScript and CSS. Nothing to compile, nothing to break.

Author friendly

Every block is a plain table in your document, documented in the block library.

Dark sections

Add a "dark" style to any section and every block inside adapts.

Accessible by default

Keyboard-friendly tabs and dialogs, visible focus rings, reduced-motion support.

Open source

Apache-2.0. Use it for client work without asking.

Design system

One set of tokens, every block in step

Change the brand color once and buttons, tabs, pricing badges, step numbers and focus rings all follow. No hunting through block files.

Questions

Do I need AEM Sites to use this?

No. It works with document authoring, DA and Universal Editor projects built on the standard boilerplate.

How do I change the colors?

Edit the variables in the :root block at the top of styles/styles.css.

Can I use it for client projects?

Yes. The license is Apache-2.0.
