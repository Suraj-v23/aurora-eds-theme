Getting a token

Sign in at admin.hlx.page with the account that has access to your project. Copy the session token the way the Admin API documentation describes, then store it only in an environment variable.

export AEM_TOKEN="paste-your-token-here"

Keeping it safe

A token acts as you, so treat it like a password.

  • Never paste it into chat, tickets, or this page.
  • Never commit it to code or a repository. Commands reference $AEM_TOKEN and nothing else.
  • Tokens expire. Sign in again and replace the variable when calls start returning 401.
