Sidebar

One row, two cells. Cell 1: a list of #links to headings (sticky, highlights the current one). Cell 2: content. Hand-written HTML in cell 2 can nest blocks with data-nested.

The navigation on the left is this block. On mobile it collapses behind a Menu button. Variants: Sidebar (docs) caps the content at a readable width, Sidebar (toc) adds an "On this page" outline built from h2 and h3. In the nav, a bold-only paragraph or heading followed by a list becomes a group. For a whole page, see the docs template.

Animation styles

Section Metadata Style: fade-up (default), zoom, slide-left, slide-right, stagger (items of every block in the section appear in sequence). Disabled for reduced motion and when visitors switch animations off.

Scroll down to the bottom of this page to see slide and zoom sections.

Theme customizer

Use the Customize button at the bottom right: theme cards (including Docs and Docs dark), accent swatches, text style and an animation switch. Disable it per page with metadata theme-panel = off.

Choices are remembered in the visitor's browser.
