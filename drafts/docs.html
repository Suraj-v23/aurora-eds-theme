Introduction

Aurora ships a calm documentation layout: a navigation column on the left, a readable content column and an "On this page" outline on the right. It is switched on with page metadata only, so authors never touch code.

Tip. Use the Customize button to switch between the light and dark docs presets.

Installation

Copy the theme into your repository and keep the boilerplate tooling. There is no build step.

git clone https://github.com/Suraj-v23/aurora-eds-theme
cd aurora-eds-theme
npm install
npm run dev

Project structure

Each block lives in its own folder with one JavaScript and one CSS file. Global tokens live at the top of styles/styles.css.

Presets

A preset only overrides CSS variables, so every block follows it automatically.

Docs preset

White background, soft grey surfaces, small radii, flat bordered cards and a quiet periwinkle accent.

Dark variant

The docs-dark preset keeps the same structure on a near-black background.

Fonts

The docs preset uses a clean system sans-serif for headings. Pick another style in the customizer if you prefer.

Customizer

Visitors can change theme, accent colour, text style and motion. Everything is stored in their browser. Add metadata theme-panel = off to hide it.
